Build new columns

Question: Which species and sizes are we placing, and how long do they stay?

Pet Code hides two facts in one cell. We split it, look up the species name, and label each pet's stay and age group. All new columns go on Clean, right next to the table.

Task 1 · Species code (LEFT + SEARCH)

COREGUIDED

In I1 type Species Code. In I2, write a formula that returns the letters before the dash in D2. It must work for 3-letter codes (DOG-S) and 2-letter codes (GP-S).

Guided start
  1. In a spare cell (like Q26), type =SEARCH("-",D18). It tells you where the dash is in GP-S.
  2. The letters you want are one less than that number.
  3. Now put SEARCH inside LEFT, in I2.
Hint 1

LEFT(text, how many letters). SEARCH finds the position of the dash.

Hint 2

=LEFT(D2,SEARCH("-",D2)-1)

Solution

SEARCH finds the dash at position 3 in GP-S, so LEFT takes 2 letters. I2 = DOG, I18 = GP. A fixed LEFT(D2,3) would give "GP-". That's why we need SEARCH. Delete the spare cell when you're done.

Task 2 · Size code and a wildcard

CORE

In J1 type Size Code. In J2, return the letters after the dash (S, M, L, or XL). Then in P15 type Large and in Q15 count Pet Codes that end in -L.

NudgeHow many letters come after the dash? The total length minus the dash position.
Hint 1

RIGHT(text, how many). LEN gives the total number of characters. In COUNTIF, * means "anything."

Hint 2

=RIGHT(D2,LEN(D2)-SEARCH("-",D2)) · =COUNTIF(D2:D501,"*-L")

Solution

J15 = XL. Large = 89. "*-L" means "ends with -L," and XL codes end with -XL. Without the dash, "*L" counts 111 (89 L + 22 XL).
