Exercise 4 · Lecture 3 · Sheet: Stats

Know your variables

Question: What kind of data is in each column, and what do the basic statistics tell us?

Before we calculate anything, we need to know what each column is. You can't average a shelter name.

Task 1 · Variable or value? Categorical or numerical?

CORE

First: is C1 a variable or a value? Is C2? Then label each column of Adoptions.

NudgeAsk: does doing math with this column make sense? If yes, can it have decimals?
Hint 1

A variable is the column (the question). A value is one answer in a cell. Numbers that are only labels (like an ID or an area code) are categorical.

Hint 2

Discrete = you count it (whole steps: 1, 2, 3). Continuous = you measure it (any decimal: 8.2 lb).

Solution

C1 variable, C2 value. A ID: categorical (a label, like an area code). B Date: either is accepted (we argued about dates in Lecture 3). C, D: categorical. E Age in whole years: discrete. F Weight: continuous. G Days: discrete. H Fee: whole dollars, so discrete (continuous also accepted).

Task 2 · Measurement scales

CORE

Pick the scale for each column. One extra: the size part of the Pet Code (S, M, L, XL).

NudgeCan I put it in order? Do the gaps mean something? Does 0 mean none?
Hint 1

Nominal = names only. Ordinal = has an order. Interval = equal gaps, no true zero. Ratio = equal gaps and a true zero.

Hint 2

0 days in shelter means none, so it's ratio. A date has no true zero (there's no "day zero"), so it's interval. S, M, L, XL has an order but the gaps aren't equal.

Solution

A, C, D nominal · B interval · E, F, G, H ratio · sizes ordinal. Reminder: nominal and ordinal are categorical, interval and ratio are numerical.
