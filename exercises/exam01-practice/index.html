The story: This dataset tracks orders placed by customers of a fictional store. Some order numbers appear multiple times because the order contains different items. All geographic data is there for shipping purposes.

One row = one item in an order. When a question says "orders", count rows. The file has 9,426 rows and 6,455 different Order IDs.

Each task on this page is one question from the Exam 1 Practice, with the same number (Q1 to Q22). On the real exam you show your work the same way: one sheet per question.

Before you start

Download both files from Canvas: Exam1-Practice.csv and exam1practice.json. Open Exam1-Practice.csv from Downloads by double-clicking it (don't copy and paste its text, or the ® signs break). Then File → Save As → Browse → Desktop, name it Exam1Practice-LastName, type Excel Workbook (*.xlsx). Then set up the data sheet in the next box.

Save often: Ctrl + S.

How to use this page

  • Each task tells you the goal and the question. It does not tell you every click. You know these tools.
  • Read the Nudge first. Still stuck? Open Hint 1 (the tool), then Hint 2 (the key step). The Solution is last. Try first.
  • GUIDED tasks show the first few clicks. You finish the rest.
  • Type your answer and click Check. CORE tasks first. EXTRA tasks if you have time.
  • Your checkmarks save on this computer.
  • Screenshot boxes: press Windows + Shift + S, drag a box around your work, then click the screenshot box on this page and press Ctrl + V. Your screenshots stay on this computer.

Show your work: every question gets its own sheet named Q1, Q2, and so on. Never answer on the data sheet. To make a question sheet: Right-click the data tab → Move or Copy → (move to end) → check Create a copy → OK. Double-click the new tab and rename it. PivotTable questions (Q15 to Q21) make their own sheet: rename it to the question number. Answers below a table start in row 9430, so row 9429 stays empty under the Total Row.

Set up the data sheet (once, before Q1)

  1. Click A1. Home → Format as Table → pick a style. Check that the range is $A$1:$L$9427 and My table has headers is checked → OK.
  2. Table Design → Total Row. The Total Row is row 9428. If Excel put a number in it (usually L9428), click that cell → arrow → None. Keep the word Total in A9428.
  3. Select columns A to L by their letters → double-click the line between any two letters (AutoFit).
  4. Make column B (Item) about twice as wide as column C (Department): right-click the letter C → Column Width → read the number → Cancel. Right-click the letter B → Column Width → type twice that number → OK.
  5. Double-click the sheet tab → type data → Enter → Ctrl + S.

Your table now runs from row 1 (headers) to row 9427, with the Total Row in row 9428. Every question sheet starts as a copy of this sheet.
