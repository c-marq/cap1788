The story: This dataset keeps track of how many vacation packages have been marketed to a large collection of customers. Those with a 1 in the last column ended up purchasing a package.

One row = one customer. The file has 4,888 rows. Some columns have blank cells. The columns table below says which.

Each task on this page is one question of the exam, with the same number as in Canvas (Q1 to Q9). The question text is the same as in Canvas; the line Where to work is added here.

In Canvas, click the exam file link in the quiz. The file exam1-travel.csv lands in Downloads. Open it from Downloads by double-clicking it. Then File → Save As → Browse → Desktop, name it Exam1Part1-LastName, type Excel Workbook (*.xlsx). Then set up the data sheet in the next box.

Save often: Ctrl + S.

Show your work: every question gets its own sheet named Q1, Q2, and so on. Never answer on the data sheet. To make a question sheet: Right-click the data tab → Move or Copy → (move to end) → check Create a copy → OK. Double-click the new tab and rename it. Answers below the table start in row 4892, so row 4891 stays empty under the Total Row.

Set up the data sheet (once, before Q1)

  1. Click A1. Home → Format as Table → pick a style. Check that the range is $A$1:$O$4889 and My table has headers is checked → OK.
  2. Table Design → Total Row. The Total Row is row 4890. Delete any value Excel put in it (usually in O4890): click that cell → arrow → None. Keep the word Total in A4890.
  3. Double-click the sheet tab → type data → Enter → Ctrl + S.

Your table now runs from row 1 (the headings) to row 4889, with the Total Row in row 4890. Every question sheet starts as a copy of this sheet.

This setup is part of the exam. Do it before Q1. The exam text writes DATA in capital letters. Excel treats data and DATA as the same sheet name.
