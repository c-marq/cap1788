The story: This dataset keeps track of how many vacation packages have been marketed to a large collection of customers. Those with a 1 in the last column ended up purchasing a package.

One row = one customer. The file has 4,888 rows. Some columns have blank cells. The columns table below says which.

Answers below a table start in row 4892.

Set up the data sheet (once, before Q1)

  1. Click A1. Home → Format as Table → pick a style. Check that the range is $A$1:$O$4889 and My table has headers is checked → OK.
  2. Table Design → Total Row. The Total Row is row 4890. Delete any value Excel put in it (usually in O4890): click that cell → arrow → None. Keep the word Total in A4890.
  3. Double-click the sheet tab → type data → Enter → Ctrl + S.

Your table now runs from row 1 (the headings) to row 4889, with the Total Row in row 4890. Q2 starts as a copy of this sheet, and the PivotTables are built from it.

This setup is part of the exam. Do it before Q1. The exam text writes DATA in capital letters. Excel treats data and DATA as the same sheet name.
