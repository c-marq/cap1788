La Ventanita Data Cleanup

0 of 8 done

The story: La Ventanita is a family bakery with 5 window counters around Miami-Dade. The owner, Doña Carmen, sent us 6 weeks of orders (September 1 to October 10, 2026). One row is one order.

She wants to know: Which store is busiest? How many orders are delivery? How many pastelitos do we sell? Her file has problems. We clean it first, then we answer her.

You will use everything from the SAT/ACT and Bees exercises. This is harder on purpose. Use the hints. They are there to help you learn.

How to use this page

  • Do one Part at a time, top to bottom. Each Part builds on the one before.
  • Type your answer in the box and click Check.
  • Stuck? Open Hint 1, then Hint 2. The Solution is last. Try first.
  • Your checkmarks save on this computer. Use the same computer to keep your place.
  • Save your Excel file at the end of every Part: Ctrl + S.

CORE

Part 1 · Explore and set up

Phase 1 and 2: get the file, protect the original, and turn the data into a table.

  1. Download the data: ventanita_orders.csv (it is also on Canvas). Open it from your Downloads folder.
  2. File → Save As → Browse → Desktop. Name: Ventanita-YourLastName. Save as type: Excel Workbook (*.xlsx). Click Save.The top of Excel says Ventanita-YourLastName.xlsx
  3. Double-click the sheet tab at the bottom. Type Original. Press Enter.
  4. Right-click the Original tab → Move or Copy… → check Create a copy → OK. Rename the new tab Cleaning.
  5. On Cleaning: click A1 → Home → Format as Table → pick a style → check My table has headers → OK.Colored rows and arrows in every column name.
  6. Click R1, type Orders. Click S1, type =COUNT(A:A)
Hint 1

COUNT counts cells that hold numbers. Every Order ID is a number. The column name "Order ID" is text, so it is not counted.

Hint 2

Why do we keep an Original sheet? If we break something on Cleaning, the original data is still safe. We never change Original.

Solution

601 orders. Keep this number in mind. Doña Carmen said she sent 600.

Part 2 · Organize

Sort to find problems, remove what the owner doesn't need, and write a Note for every change. Stay on the Cleaning sheet for Parts 2 to 5.

  1. Click the arrow in C1 (Store) → Sort A to Z. Look at the first rows. Some stores are out of order.
  2. Click the arrow in A1 (Order ID) → Sort Smallest to Largest.Order 26001 is back in row 2.
  3. Right-click I1 (Cashier) → Delete → Table Columns. Then right-click I1 (now Customer) → New Note. Type: Deleted Cashier. The owner did not ask about cashiers.
  4. Click J1. Type Trim Store, press Enter. In J2 type =TRIM(C2) and press Enter.The formula fills all the way down by itself.
  5. Right-click J1 → New Note. Type: TRIM removes extra spaces before some store names.
  6. R2: Kendall (Store) · S2: =COUNTIF(C:C,"Kendall")
    R3: Kendall (Trim) · S3: =COUNTIF(J:J,"Kendall")
Hint 1

Remember " Maryland" in the SAT/ACT file? A space before a name sorts before the letter A. Count the rows that show a Doral or Kendall above Doral.

Hint 2

If your formula shows =TRIM([@Store]) instead of =TRIM(C2), that is correct. Inside a table, Excel uses the column name.

Solution

7 rows: 3 say " Doral" and 4 say " Kendall", each with a space in front.

Store column: 105 Kendall. Trim column: 109 Kendall. COUNTIF missed the 4 with a space, just like " F" in the Bees file.

Part 3 · Clean: find and label the problems

Today we find problems and label them with Notes and yellow fill. We fix them in Part 6.

  1. Duplicates. Click the Name Box (left of the formula bar), type A2:A602, press Enter. Home → Conditional Formatting → Highlight Cells Rules → Duplicate Values → OK.
  2. Click the arrow in A1 → Filter by Color → click the red color.Two rows with the same Order ID.Right-click the second red cell → New Note: Duplicate. Delete this row on the Final sheet. Then arrow in A1 → Clear Filter From "Order ID".
  3. Stats block. Type labels: S5 Qty · T5 Unit Price · U5 Order Total. Then R6 AVERAGE · R7 MEDIAN · R8 MIN · R9 MAX · R10 COUNTBLANK · R11 COUNT.
    In column S type: S6 =AVERAGE(F2:F602) · S7 =MEDIAN(F2:F602) · S8 =MIN(F2:F602) · S9 =MAX(F2:F602) · S10 =COUNTBLANK(F2:F602) · S11 =COUNT(F2:F602)
    Select S6:S11. Drag the Fill Handle (small square, bottom right) to column U.Numbers in S6 to U11.
  4. Outlier. Look at row 9 (MAX). One MAX is much bigger than its MEDIAN. Press Ctrl + F, type that MAX number, click Find Next, then Close. Add a Note on that cell: Should be 14.50 (2 × 7.25).
  5. Missing Qty. Row 10 (COUNTBLANK) shows empty Qty cells. Arrow in F1 → uncheck (Select All) → check (Blanks) → OK. For each order, find the Qty: Order Total ÷ Unit Price. Add a Note: Qty should be ___. Then clear the filter.
  6. Missing Customer. R12: Customer blanks · S12: =COUNTBLANK(I2:I602). Filter column I for (Blanks). Look at its Order Code. Add a Note with what it should say. Clear the filter.
  7. Hold Ctrl and click each cell you put a Note on in Steps 4 to 6. Home → Fill Color arrow → Yellow. Save.
Hint 1 · Duplicates and the outlier

Filter by Color only shows up after Conditional Formatting colors some cells. If it is gray, check Step 1 again.

For the outlier: most orders are a few dollars. The MEDIAN says the middle order is about $5. Which MAX looks impossible for a bakery window?

Hint 2 · Missing values

Order 26032 is a Tostada: $8.25 ÷ $2.75 = ?. Order 26035 is a Cuban sandwich: $38.00 ÷ $9.50 = ?

The empty Customer is on order 26308. Its code starts with WU. What does every other walk-up order say in the Customer column?

Solution

Duplicate: 26141 (a Hialeah order for 2 guayaba y queso pastelitos, typed twice).

Order Total: MEDIAN 5, MAX 1450. Order 26078 is 2 Medianoches at $7.25, so it should be $14.50. Someone dropped the decimal point.

Empty Qty: 2. Order 26032 should be 3. Order 26035 should be 4. Qty COUNT is 599, not 601. That's another clue.

Empty Customer: order 26308 is a walk-up (WU), so it should say Walk-in.

Part 4 · Transform the Order Code

DL-CD hides two facts in one cell. We turn them into plain Yes or No columns. This is a nested function: LEFT runs first, then IF.

  1. K1: Delivery? · K2: =IF(LEFT(D2,2)="DL","Yes","No")
  2. L1: Card? · L2: =IF(RIGHT(D2,2)="CD","Yes","No")
  3. Right-click K1 → New Note: Turned the Order Code into Yes/No columns.
  4. R14: Delivery orders · S14: =COUNTIF(K:K,"Yes")
    R15: Card orders · S15: =COUNTIF(L:L,"Yes")
  5. Challenge: R16: Catering orders · S16: count the Order Codes that start with CT. Use the star from the Bees exercise.
Hint 1

Type K1 right next to the table, with no empty column in between. Then the formula fills down by itself. #NAME? means a quote mark is missing around "DL", "Yes", or "No".

Hint 2 · Catering

"*bumble*" meant "bumble anywhere." "CT*" means "starts with CT, then anything." Use it on column D.

Solution

Delivery 203 · Card 435 · Catering =COUNTIF(D:D,"CT*") = 18.

Extra B · First names for a thank-you text

Doña Carmen wants to text delivery and catering customers by first name. Pull the first name out of Customer.

  1. On Final, click L1. Type First Name. In L2 type:
    =LEFT(I2,SEARCH(" ",I2)-1)
  2. Scroll down. Some rows show #VALUE!. Look at their Customer. Why?
  3. Change L2 to:
    =IFERROR(LEFT(I2,SEARCH(" ",I2)-1),"Walk-in")
  4. N8: =COUNTIF(L:L,"Walk-in")
Hint

SEARCH looks for a space. "Walk-in" has a dash, not a space, so SEARCH fails. IFERROR says: if there is an error, show "Walk-in" instead.

Solution

379 walk-in orders. The other 221 orders have a real first name, like Tamara or Andres.
