The story: Sunshine Paws Rescue finds homes for pets at 5 adoption sites around Miami-Dade. The director, Ms. Yolanda, sent us every adoption from January to September 2026. One row is one adoption.

Her volunteers typed the records by hand, so the file has a few problems. Over three reviews we explore it, clean it, and answer her questions with every skill from Lectures 1 to 6.

Before you start

Download the data: sunshine_adoptions.csv. Open it from Downloads. Then File → Save As → Browse → Desktop, name it Sunshine-YourLastName, type Excel Workbook (*.xlsx). We use this same file for all three reviews.

Save often: Ctrl + S.

How to use this page

  • Each task tells you the goal and the question. It does not tell you every click. You know these tools.
  • Read the Nudge first. Still stuck? Open Hint 1 (the tool), then Hint 2 (the key step). The Solution is last. Try first.
  • GUIDED tasks show the first few clicks. You finish the rest.
  • Type your answer and click Check. CORE tasks first. EXTRA tasks if you have time.
  • Your checkmarks save on this computer.
  • Screenshot boxes: press Windows + Shift + S, drag a box around your work, then click the screenshot box on this page and press Ctrl + V. Your screenshots stay on this computer.

Your answers go on the sheets named in each task: Supplier, Adoptions (cells L1 to O1 only), and Counts.

Task 2 · Price per pound

CORE

In F1 type Price per lb. In F2 write a formula that divides the price of the bag by its size. Copy it down to F5 with the Fill Handle. Format F2:F5 as Currency.

NudgePrice per pound = price ÷ pounds. Every formula starts with an equal sign.
Hint 1

Use the / sign to divide. The Fill Handle is the small square at the bottom right of a selected cell.

Hint 2

=C2/B2, then drag the Fill Handle from F2 down to F5 (or double-click it).

Solution

=C2/B2 gives $1.40, $1.35, $1.25, $1.35. Biscayne Bites is cheapest at $1.25 per lb. But it also has the lowest rating (3.9). Cheapest is not always the best value.

Hint 1

Descriptive = what happened. Predictive = what will happen. Prescriptive = what should we do.

Hint 2

Descriptive · Predictive · Prescriptive · Business Intelligence · Data Science. Remember the minivan exercise: comparing today's prices is descriptive, guessing resale value in 5 years is predictive, and picking the van is prescriptive.
